### Verificar instalaciones:

```bash
dotnet --version  # Debe mostrar 8.0.x

```

## ?? Configuración Inicial

### 1?? Clonar el repositorio

```bash
git clone https://github.com/JillFeint/DealgestorBackend.git
cd DealgestorBackend
```

### 2?? Configurar PostgreSQL

Inicia PostgreSQL y crea la base de datos:

```sql
-- Conectarse a PostgreSQL
psql -U postgres

-- Crear la base de datos
CREATE DATABASE dealgestor_db;

-- Salir
\q
```

### 3?? Configurar `appsettings.json`

Abre `Builder/appsettings.json` y personaliza:

#### **?? JWT Secret (OBLIGATORIO):**
```json
"ConfiguracionDeTarjeta": {
  "Secret": "TU_CLAVE_SUPER_SEGURA_DE_AL_MENOS_32_CARACTERES_AQUI"
}
```

?? **IMPORTANTE:** Cambia `Secret` por una clave única y segura de al menos 32 caracteres.

#### **??? ConnectionString (OBLIGATORIO):**
```json
"ConnectionStrings": {
  "DefaultConnection": "Host=localhost;Port=5432;Database=dealgestor_db;Username=postgres;Password=TU_PASSWORD_AQUI"
}
```

### 4?? Restaurar paquetes y aplicar migraciones

```bash
cd Builder
dotnet restore
dotnet ef database update --project ../Infrastructure --startup-project .
```

---

## ?? Ejecución

```bash
cd Builder
dotnet run
```

La API estará disponible en: `https://localhost:7001/swagger`

---

## ?? Seguridad

### Validaciones de Contraseña:
- ? Mínimo 8 caracteres
- ? Al menos 1 mayúscula, 1 minúscula y 1 número
- ? Hash con Argon2id
